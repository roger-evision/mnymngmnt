    Composição por mês

    As maiores categorias têm cor própria; o resto entra em “Outras”.

    Previsto e metas por subcategoria

    Previsto é quanto você espera gastar no mês. Meta é o teto que você quer respeitar. Realizado vem dos lançamentos. Os valores são mensais; a soma de uma categoria é a soma das subcategorias.

    Categorias e subcategorias

    Cada categoria da planilha (coluna Category) vira uma subcategoria dentro de uma categoria principal. Edite os nomes para reorganizar; o mesmo nome agrupa. Categorias no formato “Grupo | Item” já entram separadas.

    Os dados ficam só neste navegador. Use “Salvar backup” para guardar metas e categorias num arquivo.
