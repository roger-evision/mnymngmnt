    Composição por mês

    As maiores categorias têm cor própria; o resto entra em “Outras”. Clique num bloco para ver as despesas.

    Fluxo anual de metas

    Meses que já têm lançamentos mostram o Realizado (vermelho com ▲ quando passou da meta); os seguintes mostram a Meta. A coluna Meta/mês vale para todos os meses; digite num mês para mudar só ele (valor em negrito) e apague para voltar ao padrão (valor em cinza). Categorias somam as subcategorias. Clique num nome ou valor realizado para ver as despesas.

    Categorias e subcategorias

    Clique numa categoria ou subcategoria para ver as despesas dela. Para reorganizar, edite os nomes: cada categoria da planilha (coluna Category) vira uma subcategoria dentro de uma categoria principal, e nomes iguais se juntam. Categorias no formato “Grupo | Item” já entram separadas.

    Os dados ficam só neste navegador. Use “Salvar backup” para guardar metas e categorias num arquivo.
